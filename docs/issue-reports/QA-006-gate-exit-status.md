# [QA-006] 门禁只打印失败不返回非零

- 状态：`Verified`
- 门禁：`quality`
- 复现入口：`npm test`

## 现象

测试报告能显示缺陷，但进程仍返回 0，CI 会把失败合并成通过。

## 预期 / 实际

- 预期：必选检查失败使命令返回非 0，并保存检查 ID、输入和实际值。
- 实际：没有进程级退出约束时，报告只是日志。

## 模拟修复

- `FIX-QA-006`：正常路径必须通过；负向夹具必须被检测；任何未检测到的预期缺陷都用 assert 使套件失败，并写 `evidence/latest-run.json`。

## 回归

- `npm test`
- 断言：至少四个 seeded defect 进入 `detected`，缺少任何一个都会触发非零退出。
